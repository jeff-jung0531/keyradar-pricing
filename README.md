# KeyRadar Pricing

AI 모델 단가표입니다. [KeyRadar](https://apps.apple.com/kr/app/keyradar/id6775709663) 앱이 이 저장소의 `pricing.json`을 받아 비용을 추정합니다.

## 이 저장소가 있는 이유

단가는 앱 안에 넣어 두면 릴리스 때마다 낡습니다. 실제로 직전 스냅샷은 73일 동안 갱신되지 않았습니다. 그래서 단가만 따로 떼어 공개해 두고, 앱이 받아가게 했습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `pricing.json` | 단가표 원본. 앱이 받아가는 파일입니다 |
| `schema.json` | `pricing.json`의 형식 정의 |
| `sources.yaml` | 프로바이더별 가격 페이지 주소와 확인 요령 |
| `dist/providers.v1.json` | 구버전 앱용으로 변환된 파일 |
| `scripts/validate.py` | 형식과 이상값 검사 |

## 갱신 방식

매일 한 번 자동으로 가격 페이지를 읽어 초안을 만들고, **바뀐 값이 있을 때만** PR을 엽니다. 사람이 차이를 확인하고 머지해야 반영됩니다. 자동으로 main에 들어가지 않습니다.

```
가격 페이지 읽기 → 이전 값과 비교 → 변경 있으면 PR → 사람이 확인 → 머지
```

## 읽는 법

- `unit`이 과금 단위입니다. `per_mtoken`은 토큰 100만 개당 USD입니다
- `checked_at`은 그 프로바이더 단가를 마지막으로 확인한 날짜입니다
- `source_url`은 그 숫자를 읽어 온 페이지입니다

## 한계

- **정가 기준입니다.** 캐시 할인, 배치 할인, 볼륨 계약가는 반영하지 않습니다
- **여기 없는 모델이 있습니다.** 단가를 확인하지 못한 모델은 넣지 않습니다. 앱은 그런 모델을 "단가 미등록"으로 세고, 0원으로 숨기지 않습니다
- **잔액이 보이는 프로바이더는 여기 없어도 됩니다.** fal, kie.ai, ElevenLabs 등은 앱이 잔액 차감으로 실제 지출을 측정합니다

## 제보

단가가 틀렸다면 이슈나 PR을 열어 주세요. `source_url`과 읽은 날짜를 함께 적어 주시면 확인이 빠릅니다.
